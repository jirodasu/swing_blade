# SWING BLADE — Pyxel試用版 v0.2.1

提供された「斬機 -ザンキ-」プレイ動画の説明画面を基準に、弾・倍率・宝石のスコアアタックへ変更。
参照動画：https://youtu.be/Map6LmVYVK4
公開版：https://jirodasu.github.io/swing_blade/

## 動画で確認できたルール

- マウスで自機を動かす。剣は移動方向の反対へ振られる。
- 剣で敵機を倒すと宝石が出現。回収すると得点。
- 敵弾は斬って消せない。剣を当てると得点倍率が上がる。
- 倍率は敵撃破・宝石回収の得点に掛かり、何もしないと低下する。
- 一定時間ごとにレベルが上がり、敵の攻撃が激しくなる。
- 自機の当たり判定は中心1ドット。敵弾に当たるとゲームオーバー。

これらは添付された55秒の録画で確認した内容。原作ソースの移植や完全一致の保証ではない。
前版のHP5・30秒クリア・接触ダメージ・速度条件付き攻撃は廃止。
敵機との接触だけでは死亡しない設定としている（動画の説明は敵弾についてのみ）。
終了時間の説明は確認できないため、今回の試作は時間制限なしのスコアアタック。
静止中も刃の重なりで敵を斬る設定としたが、静止時の攻撃可否は動画では未確定。

## 操作

- **START / SCORE ATTACK**：被弾するまで得点を稼ぐ。
- **PRACTICE / NO DEATH**：静止した標的1機＋直進する弾1発。RESETで初期状態へ。死亡なし。標的は再出現。
- **スマホ**：戦場外の左下スティック（中心48,342・半径32）をフリック。倒した方向へ移動。中央へ戻すか指を離すと停止。戦場タップでは移動しない。
- **PC**：フィールド内のマウス移動、または方向キー・WASD。
- **剣**：移動の反対方向へ追従。移動を止めたフレームで、その時点の角度を保持し角速度を0にする（ユーザー指定2-B）。移動中のみ反対方向へ回転する。
- **II / P**：一時停止。**MENU / Esc**：タイトルへ。**SND / M**：効果音。
- 画面離脱・タッチキャンセルで自動停止。再開は手動。

## 仮の調整値（原作の確定値ではない）

| 項目 | 試作の値 |

| 解像度・FPS | 240×400・60 FPS、戦場240×240 |
| 剣長 | 43 px |
| キーボード速度 | 2.4 px/フレーム。マウスは位置追従。スティックは中心5 px無反応、外側で最大速度 |
| 角度復元力 | 0.72（ユーザー指定） |

| 弾の当たり判定 | 半径3 px |

| 敵撃破／宝石 | 100／200点 × その時の倍率 |
| 宝石 | 回収範囲7 px、8秒で消滅、吸引なし |
| レベル | 15秒ごとに+1 |
| 敵機出現 | 85−(レベル−1)×8フレーム間隔、下限25 |
| 弾速 | 0.8+(レベル−1)×0.12 px/フレーム、上限2.1 |
| 敵機の射撃 | 初射撃45フレーム後。その後120−(レベル−1)×8、下限35 |

| 最大個数 | 敵機32、敵弾260、宝石100 |

数値・出現パターン・倍率再加算条件・宝石寿命は録画から厳密には決定できないため仮設定。
パラメーターは`main.py`の先頭定数と`spawn` / `fire`にある。
剣は回転と位置移動を補間して判定。弾と中心の判定も移動軌跡を使い、大きなポインター移動で弾をすり抜けない。
ヒットストップは入れず、プレイ中の時間が連続して進む。

## 起動・開発

Pyxelはネイティブ版・Web版とも2.9.9に固定。

```powershell
py -m pip install -r requirements.txt
py main.py
```

ブラウザー版は「起動する」→Pyxelの起動画面をタップ→START。
ローカル配信：`py -m http.server 8000`、`http://localhost:8000` を開く。

```powershell
py -m unittest discover -s tests -v
py build_web.py
```

`main.py`が正本。`build_web.py`で`index.html`へ埋め込む。
GitHub Actionsがmainへの更新でテスト・生成・公開を行う。
ブランチからのPages配信でも同じ設定になるよう、生成済みindex.htmlも更新する。
スマホSafari実機での操作感・音の確認は別途必要。

## 操作試作の合格条件（v0.2.1）

- 指は戦場外・左下のスティックで操作。倒した方向へ移動する。
- 中央へ戻す／指を離す／入力キャンセルで移動が止まる。
- マウスは戦場内のポインターの位置へ追従する。
- 移動停止の直後に剣の角度が固定され、その後も回らない。
- 練習は標的1機・直進弾1発・倍率・リセットだけで入力を確認できる。
- スティック、RESET、HUDは戦場外にあり、敵弾に覆われない。
- 数値テストに加え、ユーザーが意図どおりの操作感と判断して合格とする。

フリックは「倒している間は移動し、戻す／離すと停止」と解釈した。
ランサーズの入力コードの完全移植ではなく、指定された配置と操作形式を再現している。
